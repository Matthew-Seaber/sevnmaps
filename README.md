# 🗺️ SevnMaps

Discover a world full of hidden gems with SevnMaps, your ultimate travel companion!

## 🛠️ How to access
Use the live demo at the bottom of the README
### OR
- Download the project files as a `.ZIP` or clone the repo using `git clone https://github.com/matthew-seaber/sevnmaps.git` in your terminal
- Run `bun install` to install the required dependencies
- Run `bun dev` to start a local development server (default: `http://localhost:3000`)
