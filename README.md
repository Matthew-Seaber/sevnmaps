# 🗺️ SevnMaps

Discover a world full of hidden gems with SevnMaps, your ultimate travel companion! Save places to lists and collaborate with friends to design the trip of a lifetime!

## How to access
Use the live demo at the bottom of the README
### OR
- Download the project files as a `.ZIP` or clone the repo using `git clone https://github.com/matthew-seaber/sevnmaps.git` in your terminal
- Run `bun install` to install the required dependencies
- Run `bun dev` to start a local development server (default: `http://localhost:3000`)

## Key features
- Interactive map populated with hidden gems
- Track visited places and countries
- Save places to lists and collaborate with friends

*Note: UX on mobile devices may be downgraded since this website was primarily designed for PC use.*
